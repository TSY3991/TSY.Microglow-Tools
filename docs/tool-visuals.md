# 工具 icon 與介面快照

工具箱五張卡片使用各工具正式 icon；四個桌面工具下載頁在簡介與版本日期之間顯示實際介面，可點圖另開分頁放大。PriceRadar 沒有下載頁，只使用其現有 PWA icon。

素材版本、尺寸與 SHA-256 記錄在 assets/tools/manifest.json。快照來自已發布版本的 WPF 控制項，以隔離空白設定渲染，不含真實路徑或使用者檔案；不是 AI 生成的模擬介面。

## 每次工具發布與入口網站新聞

1. 先讀 Website 的 docs/update-workflow.md，核對工具最新發布版本。
2. 比對正式 icon 與目前素材；有變更才替換 icon.png，同步工具卡片及下載頁 favicon。
3. 介面有變更時，從相同發布版本重新產生 screenshot.png；使用空白或虛構資料，逐張確認無私人資訊。
4. 更新 manifest 的版本、尺寸、雜湊，以及下載頁快照的 alt、尺寸與版本標示。若 UI 無變更，可保留舊快照並保留其實際版本標示，不冒充新版本。
5. 若素材網址不變但內容改動，對所有實際引用該素材的網址同步提升 ?v=；快照連結與 img 必須指向同版本。
6. 工具網站素材先發布並驗證，再發布入口網站新聞；不能只新增新聞而漏掉已變更的 icon 或快照。兩個 repo 各自依使用者授權提交與 push。
7. 驗證桌機／手機版、圖檔載入、點圖放大、動態版本與下載連結，確認無溢出。

未改 download.js、release 日期、下載流程或 PriceRadar App。
